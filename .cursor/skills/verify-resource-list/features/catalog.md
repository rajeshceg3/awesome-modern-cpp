# Browse resource catalog
## Sub-features
Books/community/templates/libraries/tools/about sections,222 Markdown links and original attribution.
## How to get to it (user POV)
Open README, choose a section and follow a resource. The list belongs to the upstream author; the owned repository is a fork.
## Driving it with drive.py
Drive validates source link shapes/required sections, opens actual C++ Core Guidelines and Compiler Explorer resources, and records readable HTML titles/status/resolved URLs. It never runs linked code.
